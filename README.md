# OUR LITTLE DATE — версия без Firebase

## Как это работает

Здесь **нет сервера, аккаунтов и хранилищ**. Все данные живут прямо в ссылке:

1. Открой `create.html` → напиши название → получи ссылку для гостя.
2. Отправь ссылку человеку.
3. Человек откроет ссылку, выберет дату → получит **ответную ссылку**.
4. Открой ответную ссылку (ссылка с ответом) → увидишь карточку.
5. Если человек пришлёт несколько ответов, каждый откроется в `owner.html` — они сохранятся в браузере.

## Хранение ответов

Ответы сохраняются в `localStorage` твоего браузера. Это значит:
- ✅ Если открываешь ответы с того же браузера — они все накопятся в списке.
- ⚠️ Если откроешь с другого устройства/браузера — список будет пуст, но ответ из текущей ссылки всё равно отобразится.

## Как запустить

Нужен локальный сервер (открыть HTML двойным щелчком **не сработает**, потому что модули `import` требуют HTTPS или localhost).

**VS Code Live Server:**
1. Открой папку проекта в VS Code.
2. В правом нижнем углу нажми `Go Live`.
3. Переходи по появившимся ссылкам.

**Python (если установлен):**
```
python -m http.server
```

**Node.js:**
```
npx --yes serve
```

## Структура

```
index.html      страница гостя (открывается по ссылке-приглашению)
create.html     создание приглашения
owner.html      просмотр ответов
css/style.css   единая тема: чёрный / белый / бордовый + адаптивность
js/share.js     упаковка данных в ссылку и обратно
js/create.js    логика create.html
js/guest.js     логика index.html
js/owner.js     логика owner.html
js/fx.js        визуальные эффекты (свечение курсора, всплеск сердечек)
```
